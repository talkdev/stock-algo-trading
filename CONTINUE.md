
# Project Instructions

## Architecture

Understand the existing architecture before modifying code.

## Trading System

This is a production algorithmic trading system.

Do not modify trading logic without explaining:

1. Current behavior
2. Proposed behavior
3. Risk of the change
4. Backward compatibility impact

## Coding Rules

- Do not hallucinate APIs.
- Inspect existing code before creating new functions.
- Reuse existing utilities where possible.
- Do not duplicate functionality.
- Preserve existing logging.
- Preserve error handling.
- Do not remove validation.
- Do not change database schemas without explicit approval.

## Testing

Before considering a change complete:

1. Run syntax checks.
2. Run relevant unit tests.
3. Check imports.
4. Check configuration.
5. Check error paths.
6. Summarize changed files.
